# Background Music

Letakkan file musik latar di folder ini dengan nama `background.mp3`.

## Rekomendasi:

- Format: MP3
- Durasi: 2-5 menit (akan di-loop otomatis)
- Genre: Instrumental romantis, acoustic, atau piano
- Ukuran: Maksimal 5MB untuk loading yang cepat

## Sumber musik gratis:

- [Free Music Archive](https://freemusicarchive.org/)
- [Pixabay Music](https://pixabay.com/music/)
- [Mixkit](https://mixkit.co/free-stock-music/)

## Catatan:

Pastikan musik yang digunakan bebas royalti atau memiliki lisensi yang sesuai.
